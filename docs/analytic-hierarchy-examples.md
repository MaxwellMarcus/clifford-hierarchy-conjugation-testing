# Exact diagonal hierarchy examples

`analyze_diagonal_c3` is an exact, deliberately bounded checker for diagonal
gates whose entries are eighth roots of unity. Such a gate is represented by
integer exponents \(f(x)\in\mathbb Z_8\):

\[
 U|x\rangle=\exp(i\pi f(x)/4)|x\rangle.
\]

The implementation computes the unique multilinear polynomial for \(f\) on
the Boolean cube using a Möbius transform modulo eight. A diagonal gate in this
domain is Clifford exactly when every linear coefficient is even, every
quadratic coefficient is divisible by four, and every higher-degree
coefficient vanishes. These are precisely the phases generated by single-qubit
S gates, Z gates, controlled-Z gates, and a global eighth-root phase.

For each qubit, integer subtraction computes the diagonal factor in

\[
 U X_i U^\dagger=X_iD_i,\qquad
 D_i|x\rangle=\exp\left(i\pi
 [f(x\oplus e_i)-f(x)]/4\right)|x\rangle.
\]

The gate is in the third Clifford-hierarchy level exactly when every \(D_i\)
is a diagonal Clifford. Z generators commute with U, and checking the Pauli
generators suffices because the Clifford operators form a group.

## Positive example: CCZ

CCZ has phase polynomial \(f(x)=4x_0x_1x_2\). It is not Clifford because of
the nonzero cubic coefficient. Each Boolean derivative is
\(4x_jx_k\), the phase polynomial of a controlled-Z, so every conjugated X is
a Clifford. Therefore CCZ is properly in C3.

## Negative example: controlled-T

Controlled-T has \(f(x)=x_0x_1\). For example, its derivative in the first
variable is

\[
 x_1-2x_0x_1\pmod 8.
\]

Its linear coefficient is odd and its quadratic coefficient is not divisible
by four, so the corresponding diagonal factor is not Clifford. Hence a Pauli X
is mapped outside the Clifford group and controlled-T is not in C3.

These conclusions use only integer arithmetic modulo eight. The regression
tests also reproduce them with dense numerical conjugation, but that
floating-point agreement is a cross-check rather than the proof.
